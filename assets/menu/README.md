# Menu images

Put company images here (office photos, team pictures, inside jokes) for the main menu
slideshow (Phase 8).

- `.jpg` or `.png`, landscape works best, about 1280×720 is plenty.
- Only images the company is fine with showing.
- The game builds its list automatically; no code changes needed.
- Git ignores this folder, so the images stay on this PC. Copy them to the host PC.
