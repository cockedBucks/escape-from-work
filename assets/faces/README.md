# Faces (bobblehead drivers)

Put coworker face photos here to turn them into bobblehead drivers.

- Only people who agreed to be in the game.
- One image per person, named after them: `omar.jpg`, `sara.png` (lowercase, no spaces).
- Square crop of the face works best. Any size; the game shrinks it.
- After adding or removing images, run `npm run faces` (exists from Phase 4).

These images are personal photos, so git ignores this folder: they stay on this PC only.
Copy them to the host PC that runs the game.
